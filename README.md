# Reservas Madrid

Calendario para gestionar reservas de 4 apartamentos en Madrid sin cruces de fechas.

🔗 **App en vivo:** https://reservas-madrid-chi.vercel.app

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

Copia `.env.example` a `.env.local` y llena las variables con tus credenciales de Supabase.

## Stack

- Next.js (App Router)
- Supabase (Auth + Postgres)
- Tailwind CSS v4
